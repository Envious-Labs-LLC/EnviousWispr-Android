1. **HIGH, plan §0 and §7–9:** `oneway` removes the wait for service execution, but does not set a hard deadline for marshaling and kernel submission. A full async buffer returns a space error; a dead binder can fail. Neither is a wait for buffer space. The existing `runCatching` can log a **send** failure, not a later service failure. **Drop-in text:** “A remote one-way call returns after submission, without waiting for warm-up. Send errors are logged; no hard caller-side time bound is claimed.” [Android Binder threading](https://source.android.com/docs/core/architecture/ipc/binder-threading), [kernel allocation path](https://android.googlesource.com/kernel/common/+/refs/heads/android-mainline/drivers/android/binder_alloc.c).

2. **HIGH, plan §3:** Android gives **no ordering guarantee** when mixing one-way warm-up with synchronous `polishRequestForTake`, even on the same binder. Today, the synchronous warm-up queues loading before it returns. The proposed change can queue request work first and produce `LOCAL_NOT_READY`. **Drop-in text:** “For a local request, `PolishService.accept` calls `ensureModelLoaded()` before queuing request work. Test a request overtaking the one-way warm-up; preserve the watchdog fallback.” [`PolishService.kt:164–177, 369–375, 444–474`](/Users/m4pro_sv/Developer/EnviousLabs/EnviousWispr-Android/.claude/worktrees/issue-235-bounded-history-save/app/src/main/java/com/envi/wispr/polish/PolishService.kt:164), [Android `IBinder` ordering](https://developer.android.com/reference/android/os/IBinder#FLAG_ONEWAY).

3. **HIGH, plan §11.1:** The proposed frozen-before-take scene cannot prove this call: `freeze_process` needs an existing process, while `dictate_emulator` calls `restore()` and `open_recorder` requires it; `restore()` thaws whole-process freezes. A frozen service may also delay connection, so `onPolishConnected` may never run. **Drop-in text:** “Use an instrumented sender that binds first, reports connection, then calls one-way warm-up on main while the host freezes `:polish`; assert prompt return and thaw. Test frozen-process word fallback separately. Do not count a pre-take freeze as warm-up proof.” [`wispr_eyes.py:2589–2626, 2997–3000, 4156–4162`](/Users/m4pro_sv/Developer/EnviousLabs/EnviousWispr-Android/.claude/worktrees/issue-235-bounded-history-save/scripts/uat/wispr_eyes.py:2589).
