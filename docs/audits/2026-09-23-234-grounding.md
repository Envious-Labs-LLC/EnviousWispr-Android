## E. Recommended design

- Return audio/ASR bind outcome separately from polish availability; only the first two can block capture.
- Latch polish failure for this take. On a disconnect before ASR answers, record it and keep waiting for ASR.
- On nonblank ASR text, publish deterministic fallback if polish is unavailable; preserve normal empty-text and ASR-failure endings.
- Claim or close the polish request once before fallback so a late outcome cannot publish or overwrite facts.
- If polish reconnects during the same take, keep using fallback; consider it again on the next take.
- Apply this to Cloud too: its provider call runs inside `:polish` ([PolishService.kt:377](/Users/m4pro_sv/Developer/EnviousLabs/EnviousWispr-Android/.claude/worktrees/audit-report-2026-09-23/app/src/main/java/com/envi/wispr/polish/PolishService.kt:377)).
