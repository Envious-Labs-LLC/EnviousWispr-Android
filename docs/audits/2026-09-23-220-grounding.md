## F. Already solved?

**Recommendation: keep the existing `CaptureLink` and append-only legacy AIDL; skip V2 for this low-severity finding.** It already segregates production calls. Android’s [app AIDL guidance](https://developer.android.com/develop/background-work/services/aidl) requires backward compatibility; [Stable AIDL](https://source.android.com/docs/core/architecture/aidl/stable-aidl) is a platform build-system versioning mechanism, not a smaller interface supplied automatically to this app. A second binder selected by action is feasible: [AOSP stores binders by intent comparison](https://android.googlesource.com/platform/frameworks/base/+/d8cdf4267a432cd8c4601883f3404a057895bbf6/services/core/java/com/android/server/am/ActiveServices.java#4240). It adds a cross-process contract and lifecycle work. Other binders beyond the listed files are **UNCHECKED**.
