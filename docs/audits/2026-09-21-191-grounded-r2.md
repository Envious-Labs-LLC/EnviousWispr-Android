   181	1. **Sweep A (mechanical, scripted, one commit).** `scratchpad/191-sweep-visibility.py` inserts `internal `
   182	   before each of the 214 declarations (the 227 minus the 13 framework rows), file by file, at the exact

   207	     check is a drift guard for the shape this change leaves, not a type checker.
