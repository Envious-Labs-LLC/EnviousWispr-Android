## 3. Design

Derive precompiled prefix/suffix matchers from scalar entries of the existing punctuation map. Match one or two identical marks, reject a run joined to another punctuation mark/ellipsis, and require a token boundary after a suffix. Only horizontal separation is consumed; preserve line breaks. Remove the engine mark while keeping the command phrase and a safe separating space. Run this preparation once before conversion; then retain the existing command replacements, safety checks and language gate. Do not globally collapse marks or merge command phrases.

Wrap the existing setup layout in BoxWithConstraints after system/IME padding. Keep the current560dp short-window boundary, but read the actual maxHeight. In short non-demo windows, omit the logo and scroll the whole natural-height body/footer; in tall windows retain the weighted independently scrolling body. Demo remains bounded/weighted and owns its own scene layout. Key scroll state to the onboarding stage so advancing does not retain a prior step’s bottom position.
