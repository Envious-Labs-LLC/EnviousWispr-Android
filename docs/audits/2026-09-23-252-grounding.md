## D. Recommended design

- Make deterministic preparation return `PreparedText.Fallback`, tracking each completed text step.
- Catch `Exception` around each vocabulary, detection, and cleanup step; never catch VM errors.
- On a preparation failure, return the last good text with a fallback reason that produces the existing notice.
- Protect the pre-request restore in `prepare` too, so a failure there still reaches one fallback handoff.
- For a failed restore of a valid engine answer, hand back that un-restored answer with the failure notice.
- Add `AppDefect.OwnerPolishPreparationFailed`: existing defects describe different failures. Route it through [`reportFailure`, lines 340–343](/Users/m4pro_sv/Developer/EnviousLabs/EnviousWispr-Android/app/src/main/java/com/envi/wispr/ui/TakePolishController.kt:340), preserving the one-defect gate and first-wins delivery.
