## D3. The parser cap

**FOUND.** Explicit depth limiting is the known fix and the plan is directionally correct. `kotlinx-serialization-json` 1.8.1 inherited a deep-recursion mechanism rather than a configurable maximum; its changelog records switching to deep recursion for deeply nested JSON. A true maximum-depth rejection was added later specifically to return a decoding error instead of a random stack overflow ([official changelog](https://github.com/Kotlin/kotlinx.serialization/blob/master/CHANGELOG.md), [official release notes](https://github.com/Kotlin/kotlinx.serialization/releases)).

The plan’s “deepest is 5” is off by one if the root container counts: Gemini walks root object, candidates array, candidate object, content object, parts array, part object, then text (`:957`). The other paths are OpenAI Responses five containers (`:955`), OpenAI Chat four (`:956`), Claude three (`:958`), Ollama two (`:959`), and NONE zero (`:960`). Sixty-four remains ample. `valueAt` is iterative, not recursive (`:1153-1164`), and the text helpers add no unbounded recursion (`:1166-1191`).

The new guard arms only on malformed or hostile provider input, not an ordinary response. That is acceptable because it replaces recovery from an `Error` with deterministic refusal.

**Exact parser shape:**

```kotlin
private fun parseValue(depth: Int): Any? {
    skipWhitespace()
    require(index < input.length) { "missing value" }
    return when (input[index]) {
        '{' -> {
            require(depth < MAX_DEPTH) { "JSON nesting exceeds $MAX_DEPTH" }
            parseObject(depth + 1)
        }
        '[' -> {
            require(depth < MAX_DEPTH) { "JSON nesting exceeds $MAX_DEPTH" }
            parseArray(depth + 1)
        }
        '"' -> parseString()
        't' -> parseLiteral("true", true)
        'f' -> parseLiteral("false", false)
        'n' -> parseLiteral("null", null)
        '-', in '0'..'9' -> parseNumber()
        else -> throw IllegalArgumentException("invalid JSON")
    }
}
```

> Define depth as the number of open object or array containers. Root is depth 1; 64 containers parse and 65 return null.
